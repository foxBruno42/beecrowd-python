# 🐍 Beecrowd - Python Studies

Repositório dedicado à prática, consolidação de sintaxe e busca por fluidez (*Pythonic way*) através da resolução sistemática de problemas na plataforma **Beecrowd** (antigo URI Online Judge).

---

## 🎯 Objetivo do Repositório

Embora a lógica de programação e a arquitetura de sistemas já façam parte do dia a dia, o foco aqui é **queimar o atrito de sintaxe** na linguagem Python. A meta é passar pelos fundamentos, dominar as estruturas nativas, funções embutidas e boas práticas da linguagem através de exercícios práticos e progressivos.

---

## 📂 Estrutura do Repositório

Os códigos estão organizados seguindo as categorias oficiais do Beecrowd:

| Categoria | Descrição | Status |
| :--- | :--- | :--- |
| **Iniciante** | Estruturas condicionais, loops, entrada/saída padrão e aritmética básica. | 🔄 Em andamento |
| **Matemática** | Algoritmos numéricos, primos, MMC/MDC e geometria. | ⏳ Em breve |
| **Strings** | Manipulação de texto, fatiamentos, buscas e formatação. | ⏳ Em breve |
| **Estruturas** | Listas, dicionários, filas, pilhas e conjuntos. | ⏳ Em breve |
